# 个人记账系统 PRD

## 1. 产品目标

为个人用户提供一个简单可靠的本地记账工具，支持日常收入支出记录、按月查看收支情况、导出 CSV 账单。

## 2. 用户需求

- 快速记录一笔收入或支出。
- 能按月份回顾账单。
- 能看到本月收入、支出和结余。
- 能知道主要支出分类。
- 能导出 CSV 用于表格软件查看。

## 3. 功能范围

| 编号 | 功能 | 优先级 | 描述 |
| --- | --- | --- | --- |
| F1 | 添加账目 | P0 | 记录日期、类型、分类、金额、备注 |
| F2 | 查看账目 | P0 | 查看全部或指定月份账目 |
| F3 | 月度汇总 | P0 | 统计收入、支出、结余和支出分类 |
| F4 | CSV 导出 | P0 | 导出固定表头的 CSV |
| F5 | 数据校验 | P0 | 检查日期、月份、金额、分类 |
| F6 | 本地持久化 | P0 | JSON 文件存储 |

## 4. 非目标

- 不支持多人账本。
- 不支持预算提醒。
- 不支持图表。
- 不支持云同步。

## 5. 业务规则

- 金额必须为正数。
- 金额显示和保存为两位小数。
- 支出不以负数保存，而是通过 `type=expense` 表示。
- 月度汇总只统计指定月份。
- 分类汇总只统计支出，不统计收入分类。

## 6. 验收摘要

验收重点是 CLI 行为、金额精度、汇总正确性、CSV 表头和异常输入处理。
