# 图书借阅管理系统 PRD

## 1. 产品目标

为小型图书管理场景提供一个可离线运行的借阅管理工具，帮助管理员维护图书、读者和借阅状态。

## 2. 用户角色

- 图书管理员：录入图书、注册读者、处理借还书。
- 读者：通过管理员完成借阅和归还。
- 班级负责人：查看库存和逾期情况。

## 3. 功能范围

| 编号 | 功能 | 优先级 | 描述 |
| --- | --- | --- | --- |
| F1 | 初始化数据库 | P0 | 创建 SQLite 表 |
| F2 | 图书入库 | P0 | 新增图书或增加副本 |
| F3 | 读者注册 | P0 | 创建或更新读者 |
| F4 | 借书 | P0 | 校验库存和读者后创建借阅 |
| F5 | 还书 | P0 | 关闭未归还借阅 |
| F6 | 库存查询 | P0 | 显示总册数和可借册数 |
| F7 | 逾期查询 | P0 | 显示超过 due_at 未还的借阅 |

## 4. 非目标

- 不做罚款计算。
- 不做预约排队。
- 不做读者自助登录。
- 不做 Web 页面。

## 5. 业务规则

- 借期固定 14 天。
- 归还日期可以晚于 due_at，但本版本只记录逾期，不计算罚款。
- 当前未归还借阅影响 available 数量。
- 同一读者不能重复借同一本未归还图书。
- `books` 命令必须反映最新库存状态。

## 6. 验收摘要

验收重点是 SQLite 持久化、借还状态变化、库存数量、逾期判断和异常路径。
