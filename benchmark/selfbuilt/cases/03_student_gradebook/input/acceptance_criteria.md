# 学生成绩管理系统验收标准

## 1. 总体验收原则

系统必须从空 `workspace/` 开始实现为一个可运行的 Python 项目。验收时使用以下入口启动：

```bash
python -m student_gradebook
```

并且必须支持：

```bash
python -m student_gradebook --file <数据文件路径>
```

成品必须是持续交互式 TUI。启动后应显示菜单，用户可以在同一会话中连续完成新增学生、新增课程、录入成绩、查询、统计、排名、保存和退出。不能只实现一次一个命令的脚本，也不能要求用户手动发送请求。

## 2. TUI 入口和菜单

### AC-01 启动进入 TUI

给定空数据文件或不存在的数据文件，执行 `python -m student_gradebook --file gradebook.json` 后：

- 退出前应进入交互式主菜单。
- stdout 包含 `学生成绩管理系统`。
- 菜单至少包含以下选项：
  - `1. 新增学生`
  - `2. 新增课程`
  - `3. 录入成绩`
  - `4. 修改成绩`
  - `5. 删除成绩`
  - `6. 按学生查询`
  - `7. 按课程查询`
  - `8. 成绩统计`
  - `9. 排名展示`
  - `10. 保存数据`
  - `11. 重新加载`
  - `0. 退出`

### AC-02 未知菜单选项

当用户输入不存在的菜单编号，例如 `99`：

- 系统输出 `未知选项`。
- 程序不崩溃。
- 系统回到主菜单继续等待下一次输入。

## 3. 学生信息管理

### AC-03 新增学生

用户选择 `1`，依次输入：

```text
S001
Ada
Class 1
```

系统应：

- 新增学号为 `S001` 的学生。
- 输出 `已新增学生 S001 Ada`。
- 后续按学生查询时可以查到该学生。

### AC-04 学生字段校验

以下情况必须被拒绝：

- 学号为空，输出 `学号不能为空`。
- 姓名为空，输出 `姓名不能为空`。
- 学号重复，输出 `学号已存在`。

被拒绝的数据不能保存到成绩簿。

## 4. 课程信息管理

### AC-05 新增课程

用户选择 `2`，依次输入：

```text
CS101
Python
3
```

系统应：

- 新增课程编号为 `CS101` 的课程。
- 输出 `已新增课程 CS101 Python`。
- 后续按课程查询时可以查到该课程。

### AC-06 课程字段校验

以下情况必须被拒绝：

- 课程编号为空，输出 `课程编号不能为空`。
- 课程名称为空，输出 `课程名称不能为空`。
- 课程编号重复，输出 `课程编号已存在`。
- 学分不是数字，输出 `学分必须是数字`。

被拒绝的数据不能保存到成绩簿。

## 5. 成绩录入、修改和删除

### AC-07 录入成绩

前置条件：

- 已存在学生 `S001 Ada`。
- 已存在课程 `CS101 Python`。

用户选择 `3`，依次输入：

```text
S001
CS101
95
```

系统应：

- 新增 `S001` 在 `CS101` 下的成绩记录。
- 输出 `已录入成绩 S001 CS101 95.00`。
- 后续按学生查询和按课程查询都能看到该成绩。

### AC-08 修改成绩

前置条件：已存在成绩 `S002 CS101 75.00`。

用户选择 `4`，依次输入：

```text
S002
CS101
80
```

系统应：

- 将该成绩修改为 `80.00`。
- 输出 `已修改成绩 S002 CS101 80.00`。
- 后续查询、统计和排名都使用新分数。

### AC-09 删除成绩

前置条件：已存在成绩 `S001 MATH 88.00`。

用户选择 `5`，依次输入：

```text
S001
MATH
```

系统应：

- 删除这条成绩记录。
- 输出 `已删除成绩 S001 MATH`。
- 后续按学生查询 `S001` 时不再显示 `MATH` 成绩。

### AC-10 成绩字段校验

以下情况必须被拒绝：

- 学号为空，输出 `学号不能为空`。
- 课程编号为空，输出 `课程编号不能为空`。
- 学生不存在，输出 `学生不存在`。
- 课程不存在，输出 `课程不存在`。
- 分数为空或不是数字，输出 `成绩必须是数字`。
- 分数小于 0 或大于 100，输出 `成绩必须在 0 到 100 之间`。
- 重复录入同一名学生同一门课程成绩，输出 `成绩记录已存在`。
- 修改或删除不存在的成绩，输出 `成绩记录不存在`。

无效成绩不能写入成绩簿。

## 6. 按学生查询

### AC-11 查询学生成绩和平均分

前置数据：

- 学生 `S001 Ada Class 1`。
- 课程 `CS101 Python`。
- 成绩 `S001 CS101 95.00`。

用户选择 `6`，输入：

```text
S001
```

系统应输出：

- `学生 S001 Ada Class 1`
- `CS101 Python 95.00`
- `学生平均分: 95.00`

如果学生存在但没有成绩，应输出学生基本信息和 `暂无成绩`。

如果学生不存在，应输出 `学生不存在`。

## 7. 按课程查询

### AC-12 查询课程成绩和课程统计

前置数据：

- 课程 `CS101 Python`。
- 学生 `S001 Ada`，成绩 `95.00`。
- 学生 `S002 Bob`，成绩 `80.00`。

用户选择 `7`，输入：

```text
CS101
```

系统应输出：

- `课程 CS101 Python`
- `S001 Ada 95.00`
- `S002 Bob 80.00`
- `课程平均分: 87.50`
- `最高分: S001 Ada 95.00`
- `最低分: S002 Bob 80.00`

如果课程存在但没有成绩，应输出课程基本信息和 `暂无成绩`。

如果课程不存在，应输出 `课程不存在`。

## 8. 成绩统计

### AC-13 课程统计

用户选择 `8`，再选择 `1`，输入课程编号 `CS101`。

系统应输出：

- `课程 CS101 Python`
- `成绩人数: 2`
- `课程平均分: 87.50`
- `最高分: S001 Ada 95.00`
- `最低分: S002 Bob 80.00`

### AC-14 总体统计

用户选择 `8`，再选择 `2`。

系统应输出：

- 学生人数。
- 课程数量。
- 成绩记录数量。
- 全部成绩平均分。

如果没有任何成绩，系统不能崩溃，应输出 `暂无成绩` 或将全部成绩平均分显示为 `0.00`。

### AC-15 无效统计方式

用户选择 `8` 后输入无效统计方式，例如 `x`：

- 系统输出 `无效统计方式`。
- 系统回到主菜单。

## 9. 排名展示

### AC-16 按课程排名

前置数据：

- `S001 Ada` 的 `CS101` 成绩为 `95.00`。
- `S002 Bob` 的 `CS101` 成绩为 `80.00`。

用户选择 `9`，再选择 `1`，输入 `CS101`。

系统应输出：

```text
#1 S001 Ada 95.00
#2 S002 Bob 80.00
```

排序规则：

- 分数降序。
- 分数相同按学号升序。

### AC-17 按总分排名

前置数据：

- `S001 Ada` 至少有一条成绩，总分为 `95.00`，平均分为 `95.00`。
- `S002 Bob` 至少有一条成绩，总分为 `80.00`，平均分为 `80.00`。

用户选择 `9`，再选择 `2`。

系统应输出：

```text
#1 S001 Ada 总分 95.00 平均分 95.00
#2 S002 Bob 总分 80.00 平均分 80.00
```

排序规则：

- 总分降序。
- 总分相同按平均分降序。
- 平均分也相同按学号升序。

### AC-18 无效排名方式

用户选择 `9` 后输入无效排名方式，例如 `x`：

- 系统输出 `无效排名方式`。
- 系统回到主菜单。

## 10. 数据保存与重新加载

### AC-19 保存 JSON 文件

用户完成学生、课程和成绩录入后，选择 `10`。

系统应：

- 将数据保存到 `--file` 指定的 JSON 文件。
- 输出 `保存成功`。
- JSON 文件使用 UTF-8 编码。
- JSON 顶层包含 `students`、`courses`、`grades`。

保存后的示例结构：

```json
{
  "students": [
    {
      "student_id": "S001",
      "name": "Ada",
      "class_name": "Class 1"
    }
  ],
  "courses": [
    {
      "course_code": "CS101",
      "name": "Python",
      "credit": 3.0
    }
  ],
  "grades": [
    {
      "student_id": "S001",
      "course_code": "CS101",
      "score": 95.0
    }
  ]
}
```

### AC-20 启动时重新加载历史数据

给定已经保存过的 JSON 文件，再次执行：

```bash
python -m student_gradebook --file gradebook.json
```

系统应：

- 自动加载历史学生、课程和成绩。
- 用户可以直接按学生或按课程查询历史数据。
- 查询结果与保存前一致。

### AC-21 菜单重新加载

用户选择 `11` 时，系统应从当前 JSON 文件重新加载数据，并输出 `重新加载成功`。

## 11. 文件损坏处理

### AC-22 非法 JSON 文件

如果 `--file` 指向的文件存在但不是合法 JSON，例如内容是：

```text
{not-json
```

启动程序时：

- 程序返回非 0。
- stderr 包含 `成绩文件无效`。
- stdout 不应出现主菜单，也不应提示用户继续输入。

## 12. 输出格式和数值格式

### AC-23 分数格式

以下所有输出中的分数、平均分和总分必须保留两位小数：

- 成绩录入成功提示。
- 成绩修改成功提示。
- 按学生查询。
- 按课程查询。
- 课程统计。
- 总体统计。
- 课程排名。
- 总分排名。

例如：

- `95.00`
- `87.50`
- `0.00`

### AC-24 查询和排名稳定性

为了便于人工阅读和自动化验证：

- 同一学生的课程成绩建议按课程编号升序输出。
- 同一课程的学生成绩建议按学号升序输出。
- 课程排名按分数降序、学号升序输出。
- 总分排名按总分降序、平均分降序、学号升序输出。

## 13. Oracle 覆盖摘要

隐藏 oracle 测试会覆盖以下能力：

- 新增学生信息。
- 新增课程信息。
- 录入学生成绩。
- 修改学生成绩。
- 删除学生成绩。
- 按学生查询成绩。
- 按课程查询成绩。
- 计算单个学生平均分。
- 计算课程平均分、最高分、最低分。
- 按课程排名。
- 按总分排名。
- 保存数据并重新加载。
- 学号重复。
- 课程重复。
- 分数越界。
- 缺失字段。
- 无效输入。
- TUI 或交互入口是否存在。
