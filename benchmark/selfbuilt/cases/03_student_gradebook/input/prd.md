# 学生成绩管理系统 PRD

## 1. 产品目标

为教师提供一个轻量成绩处理工具，减少手动计算总评、等级和班级统计的工作量。

## 2. 目标用户

- 任课教师。
- 助教。
- 课程项目评分人员。

## 3. 核心功能

| 编号 | 功能 | 优先级 | 描述 |
| --- | --- | --- | --- |
| F1 | CSV 导入 | P0 | 读取学生原始成绩 |
| F2 | 总评计算 | P0 | 按权重计算 total |
| F3 | 等级转换 | P0 | 将 total 转换为 A-F |
| F4 | 报告导出 | P0 | 输出包含 total 和 letter 的 CSV |
| F5 | 班级统计 | P0 | 输出人数、均分、最高/最低和等级分布 |
| F6 | 数据校验 | P0 | 校验列、学号、姓名和成绩 |

## 4. 非目标

- 不做图形界面。
- 不做数据库。
- 不做多课程管理。
- 不做学生登录。

## 5. 业务规则

- CSV 输入行顺序必须在报告中保留。
- 学号是唯一标识。
- total 和 average_total 输出都保留两位小数。
- 等级边界值必须准确，例如 90.00 是 A，80.00 是 B。

## 6. 验收摘要

验收重点是计算正确性、边界等级、CSV 表头、异常行处理和统计输出。
