# 会议室预约系统 PRD

## 1. 产品目标

为小团队提供一个轻量会议室预约 API，减少口头预约和时间冲突。系统通过 HTTP JSON 接口提供会议室管理和预约管理能力。

## 2. 用户角色

- 行政管理员：维护会议室列表。
- 普通员工：创建和取消会议室预约。
- 团队成员：查看某天的会议室占用情况。

## 3. 功能范围

| 编号 | 功能 | 优先级 | 描述 |
| --- | --- | --- | --- |
| F1 | 健康检查 | P0 | 提供 `/health` |
| F2 | 创建会议室 | P0 | 添加会议室并校验名称唯一 |
| F3 | 查看会议室 | P0 | 按 ID 查看会议室列表 |
| F4 | 创建预约 | P0 | 预约指定会议室时间段 |
| F5 | 冲突检测 | P0 | 阻止同会议室 active 预约重叠 |
| F6 | 查询预约 | P0 | 按日期和会议室过滤 |
| F7 | 取消预约 | P0 | 将 active 预约改为 cancelled |

## 4. 非目标

- 不做用户登录和权限控制。
- 不做邮件通知。
- 不做周期性会议。
- 不做前端页面。
- 不做跨时区处理。

## 5. 业务规则

- 会议室名称唯一。
- 已取消预约不参与冲突检测，也不在查询列表中返回。
- 时间边界相接不算冲突。
- 所有 API 都返回 JSON，错误也返回 JSON。
- SQLite 数据库路径由 `create_app(db_path=...)` 注入，便于测试隔离。

## 6. 验收摘要

验收重点是 Flask 工厂函数、HTTP 状态码、JSON 响应、SQLite 持久化、时间冲突检测和取消后释放时间段。
